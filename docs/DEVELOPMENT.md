原型评审发现，缺少日期会使已有原文支撑全部消失。本轮将三项原文支撑与来源有效性分开，保留已有内容，同时要求每项支撑有当前有效来源。新增真实字段变化与规则建议的前后对照；资料实际变化时撤回旧人工判断，无变化保存则保留结论。

三行交接卡整理业务、证据编号与下一步，可复制、下载并带入交接说明、CSV 和 Markdown 证据包。用量、预算、采购时间未采集时明确标为未知。
