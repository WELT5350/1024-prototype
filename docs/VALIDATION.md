## 规则与数据测试覆盖

17 项测试覆盖：完整候选、缺失日期、工具技能、私有部署、过期与冲突；120/121 天边界、非法日历、未来日期、主体错配、危险链接；不按来源数加分；人工覆盖与交接准入；重复接收不重复计企业；重新核查撤回旧交接；CSV BOM/多行/引号、模板往返、去重、全批错误回滚、枚举与长度限制；公式注入保护；备份版本与记录完整性；损坏与被禁止的存储；证据包和空批次。

## 浏览器流程覆盖

1. 读取证据、填写草稿、人工保存、刷新保留、指定负责人、模拟接收、查看同批进度、退回、导出证据包、补证后撤回旧结论。
2. 待核实不能交接；工具使用技能不会成为规则候选。
3. CSV 预览、确认导入、重复跳过、坏文件不影响原数据、重置与 JSON 恢复。
4. 手机搜索空状态、清除筛选、横向溢出检查、键盘打开与 Escape 关闭对话框。
5. 存储损坏不静默覆盖；服务不提供 `.git` 和私有 `.work` 文件。
6. 导入的 HTML 显示为原样文本，不生成图片节点；无外部页面请求。
7. 存储配额失败不显示保存成功；另一个标签页写入时旧页暂停保存。

## 发现并修正

- 已填写说明的 textarea 被嵌入 label 时，可访问名称受正文影响；改为明确的 aria-label，并由交接与退回流程回归验证。
- 对恢复数据的枚举校验改用对象自有键检查，拒绝 `__proto__` 等非支持状态。
- 截图与视频字幕分开处理，交付的静态预览不保留录制辅助字幕。
