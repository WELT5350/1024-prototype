# 演示讲稿与录制

目标时长约 90 秒，无需录音也能根据画面中的字幕理解。视频展示真实运行的界面与数据变更。

## 路演顺序

1. **问题（10 秒）**：名单本身回答不了“为什么是这家公司”。同事需要看原文、知道缺什么、决定下一步。
2. **证据（15 秒）**：星屿软件是虚构完整样本。官网证明产品和主体，招聘证明具体模型 API 职责；右侧每一项直接指向原文编号。
3. **判断与交接（20 秒）**：规则组织四项依据，人工核对后保存结论，指定演示同事并记录下一步。这是本地模拟，没有通知销售或写 CRM。
4. **缺失与纠错（20 秒）**：澄野数据缺日期，保持待核；核实日期后再判断。青禾设计仅要求使用 AI 工具，不能自动算模型服务需求。
5. **补证与进度（15 秒）**：退回写明需补内容，CSV 导入预览和去重；查看同批进度，新增商机显示未知。
6. **边界（10 秒）**：虚构数据、本地工作区，确定性核查规则；产品价值假设尚需真实用户评审。

## 重录

先在一个终端运行 `npm start`，另一个终端：

```bash
npm ci
npx playwright install chromium
npm run demo
```

录制使用全新的浏览器上下文，不影响日常工作区；实际操作过程写入 `.work/recording/`，首屏、核查和进度截图写入 `demo/`。脚本输出原始 WebM 路径。已有 MP4 可直接用于交付，无需重录。

若需要 MP4，使用已安装的 FFmpeg 对脚本输出的 WebM 转码：

```bash
ffmpeg -i <录制输出的webm路径> -c:v libx264 -pix_fmt yuv420p -movflags +faststart -y demo/evidence-desk.mp4
```

不需要在演示时输入真实企业资料、账号或密钥。不要将私有业务材料或桌面其他窗口录入视频。
