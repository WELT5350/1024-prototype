# 演示讲稿与录制

已交付视频为 **70 秒**，1440 × 960、H.264 MP4，约 2.7 MB；无需录音也能根据画面中的字幕和表单理解。视频展示真实运行的界面与数据变更。下面的讲稿可供约 90 秒的现场讲解。

## 路演顺序

1. **问题与卡片（10 秒）**：名单无法直接交接。三行卡说明业务、原文编号和下一步；预算、用量、采购时间未采集就明确未知。
2. **保留已知（10 秒）**：澄野数据已有三项原文支撑，只缺日期。来源有效性单列待核，既不清零已有内容，也不允许直接交接。
3. **补证对照（20 秒）**：补齐已核实的发布日期、采集日期。对照显示 3/3 保持不变，来源从待核到有效；实际变更只有两个日期字段。旧人工结论撤回，由人重新确认。
4. **交接能带走（15 秒）**：三行卡可复制、下载并带入交接说明。指定负责人只生成本地模拟记录，不发送消息或写 CRM。
5. **反例与同批进度（10 秒）**：工具技能不能推出模型采购需求；CSV 导入、同批统计、未知商机以及可导出完整证据包。
6. **边界（5 秒）**：虚构数据、确定性规则、不自动核验真假；AI 用于开发与验证，真实商业价值仍待用户试用。

## 重录

先在一个终端运行 `npm start`，另一个终端：

```bash
npm ci
npx playwright install chromium
npm run demo
```

录制使用全新的浏览器上下文，不影响日常工作区；实际操作过程写入 `.work/recording/`，首屏、核查和进度截图写入 `demo/`。脚本输出原始 WebM 路径。已有 MP4 可直接用于交付，无需重录。

若需要 MP4，使用已安装的 FFmpeg 对脚本输出的 WebM 转码：

```bash
ffmpeg -i <录制输出的webm路径> -c:v libx264 -pix_fmt yuv420p -movflags +faststart -y demo/evidence-desk.mp4
```

不需要在演示时输入真实企业资料、账号或密钥。不要将私有业务材料或桌面其他窗口录入视频。
